# Webarchive Extractor

> I'm not sure if it is really an "Extractor"...

The `.webarchive` format is [deprecated](https://developer.apple.com/documentation/webkit/webarchive), but I wanted to read it on Windows or Android.\
So, I found the brilliant [pywebarchive](https://github.com/bmjcode/pywebarchive) and checked its dependency.\
Fortunately, with [Pyodide](https://pyodide.org), we can run the module entirely in the browser!
