# 초성, 중성, 종성을 이용한 단어 검색
## 설명
1. 단어를 검색할 때 초성, 중성, 종성을 조합하여 검색할 수 있습니다.
2. 일반 단어 검색, 초성 검색, 종성 검색은 자동으로 탐지합니다.
3. 종성 검색은 오인식 방지를 위해 따로 표기를 해야합니다.
4. 종성 없음을 표기할 때 `.`를 사용합니다.
5. 복합검색을 사용해 복잡한 단어를 찾아보세요.
6. `%`(임의의 문자열)와 `_`(임의의 한 문자)을 통해 강력한 검색을 해보세요. 


> **주의 사항** DB를 Base64임베딩 하여 저장하였기 때문에 용량이 매우 큽니다. (약 12MB)

## 표제어 모음
[국립국어원 표준국어대사전 표제어 DB](https://github.com/korean-word-game/db)를 사용하였습니다.

## 사용 기술
- sql.js: SQLite의 WASM 포트
- Claude: 웹 페이지 제작

## 고지사항
데이터 전처리, DB 설계를 제외한 모든 클라이언트 측 코드는 Claude를 사용하여 작성 후 수정하였습니다.
